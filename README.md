## Zero AI / Zero-OS

**Pure Logic** is the foundational meta-reasoning discipline. **Zero AI** is the machine architecture intended to implement it across perception, memory, verification, objectives, planning, strategy, self-investigation, self-modification, experimentation, and long-term learning. **Zero-OS** is the implementation and research environment used to build, enforce, and test parts of that architecture.

Zero-OS includes a local OS-style control surface, Zero AI, security tooling, packaging flows, a Windows-native shell, experimental native boot work, and research implementations of Pure Logic authority and correction mechanisms.

## Quick Start

- Windows easiest path: download the native app or portable package from [GitHub Releases](https://github.com/Viomnz/Zero-OS/releases)
- Windows from the repo: double-click `Zero OS QuickStart.cmd`
- Any OS with Python: run `python zero_os_quickstart.py`
- macOS or Linux shell: run `./zero_os_quickstart.sh`
- macOS Finder: double-click `Zero OS QuickStart.command`

```powershell
git clone https://github.com/Viomnz/Zero-OS.git
cd Zero-OS
.\zero_os_launcher.ps1 first-run
python zero_os_ui.py
```

## Project status

Zero-OS is substantial and usable for local workflows, demos, development, security tooling, Zero AI experiments, and Pure Logic implementation research. It remains pre-1.0, with the standalone native OS/kernel path and several advanced autonomy systems still experimental.
